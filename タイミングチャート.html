処理説明・物理式

1. パルス信号生成（位相積分法）

回転数センサは歯数Zのギアを検出し、1回転あたりZ個のパルスを出力します。

パルス周波数 f = (RPM × Z) / 60 [Hz]
パルス間隔 T = 60 / (RPM × Z) × 1000 [ms]

位相積分によるパルス生成

シミュレーションでは、回転数を時間積分して位相を算出し、パルスを生成します。

  1. 周波数算出: 現在のRPMから瞬時周波数を計算
    freq = (currentRpm × teeth) / 60000 [kHz]
  2. 位相積分: 周波数を時間積分して位相（パルス数の連続値）を更新
    currentPhase += freq × dt
  3. パルス検出: 位相の整数部が増加した瞬間にパルスを出力
    if (floor(currentPhase) > floor(prevPhase)) → パルス発生

この方法により、回転数が変動しても正確なパルスタイミングを再現できます。

2. フリーランカウンタ

10ns分解能のカウンタが常時カウントアップ。約167.7msでオーバーフローして0にリセット。

最大値 = 167,772,150 (10ns単位) ≈ 167.7ms

3. 周期内パルス数

各制御周期内に受信したパルス数を表示します。回転数と制御周期によってパルス数が変動します。

周期内パルス数 = 今回処理時の最新パルスIndex - 前回処理時の最新パルスIndex

この値は方式Bの平均計算で分母として使用されます。パルス数が少ない（0-1個）と平均計算の精度が低下します。

4. パルス平均時間の計算方式

方式A: 固定N個平均

最新パルスから過去N個分のパルス間隔を平均します。

平均時間 = (最新エッジ時刻 - N個前エッジ時刻) / N

特徴: 安定した出力、応答が遅い

方式B: 処理周期内平均

前回処理周期後の最初のパルスから、今回処理時点での最新パルスまでの時間を、その間のパルス数で割ります。

平均時間 = (最新エッジ時刻 - 前回周期後最初のエッジ時刻) / パルス数

特徴: 応答が速い、変動が大きい

5. 回転数の計算

RPM = (1000 / 平均時間[ms]) × 60 / 歯数Z

6. 一次遅れフィルタ

ノイズ除去や急激な変動を抑制するためのローパスフィルタ。

y[n] = y[n-1] + α × (x[n] - y[n-1])
α = Δt / (τ + Δt)

τ: 時定数 (大きいほど滑らか、応答遅い)
Δt: サンプリング周期 (制御周期)

7. 0rpm判定

最新パルスから50ms以上経過した場合、停止と判定して0rpmを出力。
